# Results Layout

The `results/` directory stores experiment artifacts generated by the sweep runners.

## Subdirectories

- `raw/`: trial-level CSV outputs for each experiment
- `aggregated/`: summary CSV files grouped by sweep variable and algorithm
- `logs/`: per-run metadata snapshots, typically timestamped JSON files

## Naming Convention

- `raw/<experiment>.csv`: one row per trial and algorithm evaluation
- `aggregated/summary_<experiment>.csv`: mean metrics grouped by the experiment axis and algorithm
- `raw/runtime_breakdown_<algorithm>.csv`: trial-level timing breakdown by phase
- `aggregated/summary_runtime_breakdown_<algorithm>.csv`: mean timing breakdown by phase
- `raw/memory_breakdown_<algorithm>.csv`: trial-level estimated memory breakdown
- `aggregated/summary_memory_breakdown_<algorithm>.csv`: mean estimated memory breakdown
- `aggregated/summary_memory_speedup_<algorithm>.csv`: baseline-vs-optimized memory deltas and savings ratios
- `aggregated/summary_speedup_<algorithm>.csv`: baseline-vs-optimized runtime and quality deltas
- `logs/<experiment>_<timestamp>.json`: run configuration and execution metadata

For non-runtime experiments, implementation-aware breakdown files include an
experiment suffix, for example:

- `raw/runtime_breakdown_omp_snr.csv`
- `aggregated/summary_runtime_breakdown_omp_snr.csv`
- `raw/memory_breakdown_improved_gomp_compression.csv`
- `aggregated/summary_memory_speedup_improved_gomp_compression.csv`

Supplementary outputs such as `ablation_clean.csv`, `ablation_noise_snr15.csv`,
and `sparsity_clean*.csv` are present for thesis comparison and should be
included where possible in the thesis. If they do not fit the main chapter
flow, use appendix or supplemental analysis instead of discarding them.

## Publishing Guidance

- Keep `raw/` and `aggregated/` if you want the repository to include reproducible benchmark outputs.
- Keep `figures/` alongside these files if plots are part of the published artifact set.
- Excluding `logs/` is usually reasonable for a cleaner public repository unless run provenance is important to your release.

## Regeneration

Regenerate all tracked outputs with:

```bash
python main.py --all
```

Regenerate text summaries for thesis handoff after changing CSV outputs:

```bash
python deepseek_ready/generate_summaries.py
```
